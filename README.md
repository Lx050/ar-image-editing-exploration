# 中国画自回归编辑：区域保真与笔墨延续 —— 实验探索路径

> 基于 **BitResEdit（Infinity-2B）** 在服务器 e2-lbx（RTX 5090 D 32GB）上的完整实验链（批次 00–44）。
> 对应学年论文《中国画自回归编辑中的区域保真与笔墨延续》。

## 一句话概述

本研究在自回归图像编辑基线 BitResEdit 上系统验证"源信息保持能否成为可检验的约束"，最终收敛于**解码约束家族**：三区域分离校正（v5）首次同时实现"编辑达成 + 背景质量 + 区域保真"三项指标。

## 核心结论

| 结论 | 证据 |
|---|---|
| 解码约束是真马，token 层是骡子 | 批次 37–40 赛马：马A/B/D（解码家族）有效，马C（token 采样约束）仅 −2.6% |
| token/潜编码层操作不敏感 | 08 批 codes 置零差异 0.0142；39 批 logits 偏置 −2.6%（机理：残差编辑 `c_edit=c_src+g·(c_tgt−c_src)` 已在代码空间置保护区为源码） |
| **三区域分离校正（v5）突破** | 批次 44：bird 鸟展翅飞走 + 保护区 4.40（50组复核口径）；peacock 缺口 16.16 + 保护区 5.03 |
| LaMa 补全的系统性色偏 | 缺口内 MAE 稳定 104.37（7 实验交叉复现），输出亮绿 vs 真值暗绿；85% 为全局色偏 |
| LaMa 不读掩码内输入 | 正确桥/错误桥/无提示三组输出像素级恒等（0.0000） |
