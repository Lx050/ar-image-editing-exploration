# 中国画自回归编辑：区域保真与笔墨延续 —— 实验探索路径

> 基于 **BitResEdit（Infinity-2B）** 在服务器 e2-lbx（RTX 5090 D 32GB）上的完整实验链（批次 00–44）。
> 对应学年论文《中国画自回归编辑中的区域保真与笔墨延续》。

## 一句话概述

本研究在自回归图像编辑基线 BitResEdit 上系统验证"源信息保持能否成为可检验的约束"，最终收敛于**解码约束家族**：三区域分离校正（v5）首次同时实现"编辑达成 + 背景质量 + 区域保真"三项指标。

## 核心结论

| 结论 | 证据 |
|---|---|
| 解码约束是真马，token 层是骡子 | 批次 37–40 赛马：马A/B/D（解码家族）有效，马C（token 采样约束）仅 −2.6% |
| token/潜编码层操作不敏感 | 08 批 codes 置零差异 0.0142；39 批 logits 偏置 −2.6%（机理：残差编辑 `c_edit=c_src+g·(c_tgt−c_src)` 已在代码空间置保护区为源码） |
| **三区域分离校正（v5）突破** | 批次 44：bird 鸟展翅飞走 + 保护区 3.74；peacock 缺口 16.16 + 保护区 5.03 |
| LaMa 补全的系统性色偏 | 缺口内 MAE 稳定 104.37（7 实验交叉复现），输出亮绿 vs 真值暗绿；85% 为全局色偏 |
| LaMa 不读掩码内输入 | 正确桥/错误桥/无提示三组输出像素级恒等（0.0000） |

```
      └─ 潜空间+输出域两级联合 (40)  缺口 16.16 / 保护区 5.03
          └─ 三区域分离校正 v5 (44)  bird 鸟展翅飞走 + 保护区 3.74

反面证据：token 采样层约束 (39) −2.6%（骡子）
```

## 探索时间线（批次 00–44）

| 阶段 | 批次 | 内容 | 关键结果 |
|---|---|---|---|
| 环境与基线 | 00–01 | 环境修复、批量编辑 | 基线可复现 |
| 保持增强 | 03–06 | 全幅进出、区域掩码、像素回贴、泛化 | 保护区 MAE 16.46→1.49 |
| 解码响应校正 | 07 | 输出域软校正 v3 | 12.91→1.94（N=11） |
| 失败尝试 | 07b–13 | 两遍 decode、潜空间搬运、非刚性变形 | 明确多条死路（维度错配、codes 不敏感） |
| 换源与背景补全 | 14–15 | 孔雀馆藏、P2/P3 补全 | LaMa 色偏 104.37；元素复用 P3 最自然 |
| 10 方向并行 | 17–25 | H1–H10 假设检验 | LaMa 不读掩码内信息；H10 验证区选优成立 |
| 深化与赛马 | 26–31 | 验证区、供体、色偏后处理 | 色偏 85% 全局；Reinhard 校正 104→20 |
| BitResEdit 内部改造 | 34–36 | 马1 指令驱动 / 马2 v4 / 马3 刚体 | **v4 潜空间迭代：缺口 17.72** |
| 解码约束赛马 | 37–40 | 门控/两遍decode/采样层/两级联合 | 马D 两级联合最强：16.16/5.03 |
| 组合管线 | 41–44 | A→D、D→A、联合网格、三区域 | **v5 三区域分离：三指标同时成立** |
